🗣️ Speaking core

How to use: read the 🗨️ question, answer out loud before opening the model answer. Then use the 🧱 structure to say it 2–3 different ways with the swap-ins (and your own real news). The goal is speed: say it without thinking.

🎧 Audio drill: Part A (About me, Work, Routine, The trip) · Part B (Sport, Food, Ordering, Making plans) · Part C (Survival, Stories, Reactions, Future plans)
